# SympTalk – Android

Android Java implementation of **SympTalk**, a Generative AI health assistant designed to help users clarify symptoms and organize information into structured patient reports for healthcare professionals.

### Features

* Generative AI-powered symptom clarification
* Structured symptom and disease information
* Patient report generation
* Conversational AI integration

### Technologies

**Java · Android Studio · XML · JSON · Retrofit · Cohere API**

> SympTalk supports symptom clarification and communication and is not intended to provide medical diagnoses.
